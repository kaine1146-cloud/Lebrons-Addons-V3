# Permanent sky themes — stage 1: visual assets

This update adds five original 1024×512 sky-gradient textures under `assets/lebronsaddons/textures/sky/`. These are design assets only. The existing sky selector saves `config.skyTheme` (0 default, 1 sunset, 2 northern lights, 3 starry night, 4 cotton candy, 5 stormy).

**Not yet implemented:** rendering these images in the Minecraft world. Do not mistake this ZIP for a functional sky replacement. To implement actual always-on sky rendering, the next stage needs a verified 26.2 sky rendering integration, plus testing against other shader mods. No world time changes should be required.

Keep the previously working JAR as a backup.
